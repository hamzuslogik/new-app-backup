# Champs techniques des produits PV et PAC

## Produit PV

| Champ | Description |
|-------|-------------|
| surface_habitable | Surface bâtie au sol (m²) |
| nb_pans | Nombre de pans |
| consommation_electricite | Consommation électricité (€) |
| orientation_toiture | Orientation de la toiture |
| zones_ombres | Zones d'ombres |
| site_classe | Site classé (OUI/NON) |
| conf_orientation_toiture | Orientation confirmée |
| conf_zones_ombres | Zones d'ombres confirmées |
| conf_site_classe | Site classé confirmé |
| conf_consommation_electricite | Consommation électricité confirmée |

## Produit PAC

| Champ | Description |
|-------|-------------|
| mode_chauffage | Mode de chauffage |
| annee_systeme_chauffage | Année du système de chauffage |
| surface_chauffee | Surface chauffée (m²) |
| consommation_chauffage | Consommation chauffage (€) |

## Champs communs

| Champ | Description |
|-------|-------------|
| surface_habitable | Surface habitable (m²) |
| nb_pieces | Nombre de pièces |
| produit | ID produit (1 = PAC, 2 = PV) |
